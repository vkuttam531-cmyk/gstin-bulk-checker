# GSTIN Bulk Checker

Chrome / Edge extension: GST portal se ek saath bahut saare GSTIN ki public details nikalkar aapki **Excel (.xlsx) ya CSV** file me fill karta hai.

> Unofficial tool. GSTN / Government of India se juda nahi hai. Captcha ko bypass nahi karta.

## Kya milta hai
Legal Name, Trade Name, Status, Registration Date, Cancellation Date, Principal Place of Business, Offices, HSN / HSN Description.

## Install kaise karein
1. **Releases** page se latest `gstin-bulk-checker-extension.zip` download karein.
2. Zip ko **extract** karein, aur us folder ko kahin permanent jagah rakhein (use delete na karein, warna extension band ho jayega).
3. Chrome me `chrome://extensions` kholein (Edge me `edge://extensions`).
4. Upar **Developer mode** ON karein.
5. **Load unpacked** dabayein aur extract kiya hua folder chunein.
6. GST portal ka **Search Taxpayer** page kholein. Right side me panel dikhega.

## Use kaise karein
1. Panel me apni **License key** daalein.
2. Apni Excel/CSV file upload karein (**📂 Apni file upload**), ya GSTIN seedhe paste karein.
3. **Mode A:** captcha khud type karein. **Mode B:** pehle GST portal par khud login karein, phir ek GSTIN khud search karein, tab Start dabayein.
4. **Start** dabayein. Ho jane par **⬇ Download** se filled file le lein.
